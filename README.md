# Paperback: Readwise Reader

A Paperback (0.9 beta) extension that shows your own Readwise Reader library as novels.

## Install
1. In Paperback: Settings > Extensions > Edit > +
2. Repository Base URL: `https://redxninja2044-cmyk.github.io/Flips_Extras/`
3. Install "Readwise Reader", open its settings, and paste your token from https://readwise.io/access_token

Home shows your Books (EPUBs and PDFs) and a Series row (your Readwise tags); tap one to filter. Each book is one long chapter.

## Hitomi (CGs + Galleries)

`src/HitomiPlus` is a fork of pisshammy's Hitomi extension
(https://github.com/pisshammy/HammyExtensions, see `LICENSE-HammyExtensions`).
Additions live in `src/HitomiPlus/plus.ts`: a gallery type picker (Artist CG, Game CG and
Image Set by default) in settings and in the search filters, and a fixed block on content involving minors.
